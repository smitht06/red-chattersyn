ChatterSyn

Twitch and YouTube live chat in one window. One input, two chats.

InstallPrivacyTermsSource code

ChatterSyn is a Chatterino-style chat client for streamers, moderators and viewers who follow a stream on both Twitch and YouTube. It shows both live chats in one merged feed and sends what you type to either chat, or both.

  • One tab per stream: a Twitch channel and a YouTube live chat side by side
  • A Stream tab that follows your own channel and connects when you go live
  • Twitch, 7TV, BTTV and FFZ emotes, animated, with an emote picker
  • Twitch badges, replies, and user cards with recent messages
  • Moderation from the user card on both platforms, where you have mod rights
  • Highlights, mentions, search, chat logs, hotkeys, and dark or light themes

Reading Twitch chat needs no account. To send messages, read YouTube chat or moderate, sign in with Twitch or Google from Settings → Accounts.

Install

macOS (Apple Silicon, macOS 14.4 or later), with Homebrew:

brew tap smitht06/chattersyn
brew trust smitht06/chattersyn
brew install --cask chattersyn

Linux (Ubuntu, Debian, Mint), from the APT repository:

curl -fsSL https://chattersyn-apt.pages.dev/chattersyn.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/chattersyn.gpg
echo "deb [signed-by=/usr/share/keyrings/chattersyn.gpg] https://chattersyn-apt.pages.dev stable main" \
  | sudo tee /etc/apt/sources.list.d/chattersyn.list
sudo apt update && sudo apt install chattersyn

Windows and every other download: the latest release on GitHub.
